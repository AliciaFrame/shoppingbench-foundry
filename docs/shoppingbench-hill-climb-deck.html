What Agent Optimizer fixed

Most baseline failures were agent failures

  • Product, Shop, and Voucher had zero strict baseline successes despite frequent exact selections.
  • Optimized orchestration made tool use sequential and bounded.
  • The runtime enforced recommendation followed by termination.
  • A separate final turn produced grounded user-facing output.

Operating principle

The LLM judge proposes.
The deterministic grader disposes.

Use the cheapest effective lever, keep one evaluation spine, test every checkpoint, and open the sealed final set only after all choices are frozen.
