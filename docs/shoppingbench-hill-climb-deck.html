Experiment design

Every climb had a gate.

1. Baseline

Freeze data, tools, model, and canonical grader.

2. Optimize

Generate candidates on disjoint optimization cases.

3. Gate

Reject candidates that do not improve the 50-case deterministic holdout.

4. Train selectively

Use RFT only when base failure is 25-50% and a calibrated reward exists.

What we learned

Five operating principles for agent improvement.

1. Deterministic gates beat vibes

LLM judges nominate. Task-specific invariants decide.

2. Calibrate before training

RFT needs a measurable 25-50% base failure regime.

3. Reward design is product design

Small weights can reshape tool behavior and create unintended strategies.

4. Evaluate checkpoints, not just finals

The final Web artifact erased almost all of the Step 10 gain.

5. Preserve lineage

Datasets, graders, configs, receipts, and raw holdouts make the story reproducible.

6. Know when to stop

Without new hard cases, another Web run would recycle evidence rather than create it.

The takeaway

Foundry gives teams a disciplined path from prompt tuning to policy learning.

Agent Optimizer fixed the configuration bottlenecks. Agentic RFT fixed the policy bottleneck. Deterministic evaluation kept both honest.
